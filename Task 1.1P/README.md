# Embedded Systems Task 1.1P: Linda's Porch & Hall Lights

Arduino Nano 33 IoT project that helps Linda find her keys safely at night. Single button press lights the porch for 30s and hallway for 60s simultaneously.

## 🖥️ **Hardware Setup**

```
Board: Arduino Nano 33 IoT 
Porch light: Green LED + 220Ω  (PIN D9)
Hall light: Yellow LED + 220Ω  (PIN D8) 
Button: (PIN D2)
```

## ⚙️ **How It Works**

1. **Press button**  Both LEDs turn **ON immediately**
2. **After 30 seconds**  Porch light (green) turns **OFF**  
3. **After 60 seconds**  Hall light (yellow ) turns **OFF**
